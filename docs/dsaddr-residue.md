# DS address residue

Generated by `python tools/dsaddr.py --report <aletheia>/src/matched -o docs/dsaddr-residue.md`; do not edit by hand.  docs/boot.md, "Fixed addresses", is the design.

`tools/dsaddr.py` rewrites every pointer cast of a DS address it can prove (a literal, a file-local constant, the parameter of a file-local register macro whose every invocation passes a DS address, or an address parameter of a function in its CALLEES table) into a call of `bw_ds_ptr`.  This file lists every DS-range literal it leaves alone, each with a category, the category's verdict and the reason.

Corpus: 33524 matched files, 3702 pointer casts rewritten (32 through a define, 28 through a macro, 13 through a callee).

The function translates that parameter itself, so a caller must pass the DS address: "yes" when a literal or a file-local DS constant leads the argument, "yes (pointer cast kept)" when the argument is a pointer cast of a DS literal, which the tool leaves alone at this position so the DS address is what arrives. A caller whose prototype has a pointer parameter disagrees with the definition's u32 on LP64.  That mismatch is in the matched code and outside what C99 guarantees; in practice the address is the first argument, which every calling convention eidos targets passes in a register (or a 4-byte stack slot on 32-bit x86), so the callee reads the DS address from its low 32 bits.
